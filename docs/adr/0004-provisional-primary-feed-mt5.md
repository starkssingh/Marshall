# ADR 0004 — Provisional primary feed: MT5 tick export

- **Status:** accepted, provisional; the primary-feed choice is superseded by ADR 0057 (Dukascopy).
  The MT5 adapter and the optional source `mt5_primary` remain.
- **Date:** 2026-09-26
- **Tasks:** DATA-003

## Context

The plan makes the execution broker's own bid/ask tick history the primary research feed, from an
MT5, cTrader or OANDA venue "to be named". Choosing the broker is an owner decision. Sprint 1 still
needs a working adapter so the ingestion path, clock handling and tests exist before real data
arrives.

## Decision

1. Implement the `SourceAdapter` protocol (`discover`, `read`, `timestamps`, `to_canonical`) and one
   adapter: the **MT5 "Export ticks" CSV** (`adapter: mt5_ticks`), the most common retail export
   format among the named options.
2. Configure it as source `mt5_primary` with clock `NY+7`, venue `tbd` and vendor "MT5 broker (to be
   named)". These are placeholders to replace, not facts.
3. Format handling: tab-separated, header `<DATE> <TIME> <BID> <ASK> [<LAST> <VOLUME> <FLAGS>]`,
   UTF-8 or UTF-16 detected from the byte-order mark, times with or without milliseconds. MT5 writes
   only the changed side on each row; `to_canonical` carries each side's latest value forward **in
   file order** (past values only) and flags rows before both sides are known `MISSING_QUOTE`.
   Carrying forward does not cross file boundaries; stitching files is a cleaning concern (DATA-007).
4. `read` returns every data line, in order, with the original timestamp text (`ts_raw`) and typed
   values; it never drops, reorders or repairs rows. `row_num` is the 0-based data-line index.
5. Tests use deterministic synthetic MT5 exports (`tests/fixtures/ticks/`, generated by
   `tests/helpers/mt5_fixtures.py`). No real market data is committed.

## Consequences

- If the owner picks cTrader or OANDA, a second adapter implements the same protocol and a new
  source id is declared; nothing downstream changes.
- Tick volume and sizes are not available from this export (sizes are NaN); FEAT-007 stays gated.
- Before ingesting real data: confirm the broker's server clock (the gap-location check in
  `tests/integration/data/test_clock_gaps.py` shows how), history depth (about 4–5 years needed),
  contract terms (`config/instruments/xauusd.yaml`) and calendar (`config/sessions.yaml`).
